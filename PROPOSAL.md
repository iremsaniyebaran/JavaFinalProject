My project is a Personal Wardrobe Management System, which is a desktop app designed to help people keep track of their clothes. I’ll be using JavaFX for the user interface and an SQLite database to save all the information securely. The app will let you add new items with details like color and type, view your entire collection in a list, edit items if you need to change something, and delete clothes you no longer own. My goal is to create a simple, easy-to-use tool that makes organizing a closet much more digital and efficient.
